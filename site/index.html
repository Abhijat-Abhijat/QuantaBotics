How a message travels

Every hop is a protocol message with a sender, receiver, task, content and step. Open any hop in the chat to see the full message.

  1. The router addresses it

    It reads the prefix, picks an agent and wraps your text in the first message.

  2. Agents do the work

    Each agent handles its task with Gemini or plain Python, and can pass the result on. The summarizer hands off to the formatter.

  3. The orchestrator streams it back

    You see each hop and the answer as it is written, not after it is done.
